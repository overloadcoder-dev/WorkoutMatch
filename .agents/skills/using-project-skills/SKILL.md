# Using Project Skills

Load only skills whose triggers match the current task. Load them when their phase begins, not all at once.

- Material web product or technical choices: `designing-web-features`.
- Accessibility, responsive UX, performance, Lighthouse, or SEO: `web-quality`.
- Feature implementation, tests, or completion checks: `implementing-web-features`.
- Bugs, failures, or unexpected behavior: `systematic-debugging`.
- Genuinely independent workstreams or medium-or-higher hallucination risk: `coordinating-subagents`.

For copy, spacing, typo, or other mechanical edits, follow repository conventions directly. Use the main agent for small or tightly connected work. Combine skills only when their responsibilities are distinct.
